# Operational Research

河南大学计算机科学与技术专业课程资料 - 运筹学。

## Directory Structure

- `slides/`: PPT,2025年,老师临近考试发的复习用的
- `exercises/`: homework, question banks.
- `notes/`: 成绩分布.
- `exams/`: 往年考试卷子(不是哥们,2013年的,给我干哪一年来了,怎么还有我前任学院,而且这学院早改名了).
